# Multi-Session

Devion allows up to five accounts to remain signed in within the same browser. This is intended for fast account switching, for example between a personal and an administrative account, without entering credentials again.

Open **Account → Sitzungen** to add an account, switch the active account, or remove a stored account. Removing an account revokes that browser session. Signing out revokes the active sessions for that account.

Multi-Session does not change the existing organisation authorization checks: after switching accounts, Devion asks for the active organization before showing the control panel.
